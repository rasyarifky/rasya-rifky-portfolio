# Media

Media utama dapat langsung menggunakan link berbagi Google Drive melalui `app/data.ts`.

Folder ini hanya diperlukan jika ingin menyimpan gambar atau video secara lokal. Contoh path lokal:

```ts
image: "/media/design-karya.webp"
video: "/media/animasi-karya.mp4"
```

Untuk Google Drive, gunakan link berbagi biasa dan atur akses menjadi **Siapa saja yang memiliki link**.
